# Recomp 8: publish through GitHub Pages

## Publish once
1. Sign in to GitHub.
2. Create a new public repository named `recomp-8`.
3. Open the repository and select **Add file > Upload files**.
4. Extract the ZIP first, then upload all six files from the extracted folder. Do not upload the ZIP itself.
5. Select **Commit changes**.
6. Open **Settings > Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Select **main** and **/(root)**, then select **Save**.
9. Wait about 1 to 3 minutes. GitHub Pages will display the HTTPS address.

## Install on iPhone
1. Open that HTTPS address in Safari, not inside the GitHub app or another preview.
2. Allow the page to load fully once while online.
3. Tap **Share > Add to Home Screen > Add**.
4. Launch Recomp 8 from the new Home Screen icon.
5. Test offline mode only after the first complete online load.

## Important
Workout data is stored on the specific browser/app installation. Use **Export data** periodically, especially before clearing Safari data, deleting the Home Screen app, or changing phones.
